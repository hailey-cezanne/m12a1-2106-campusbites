AI Usage — CampusBites

Week 1 — 24 September 2026

For Week 1, I used AI to help me get started with the initial structure and layout of our CampusBites website. Since the M12A1 folder was still empty, AI helped me plan how the website could be organized and create a starting point for the project.

AI assisted in creating the first four HTML pages, the basic CSS styling and responsive layout, and simple JavaScript features such as the search and category functions. It also helped create the README, Week 1 report, and this AI usage log.

For the content, placeholders were used instead of making up actual HAU cafeteria stalls, reviews, or other information that we have not gathered yet. No external frameworks, backend systems, or external images were added.

The initial code was created with AI assistance and will serve as a starting point for the project. I will continue reviewing, editing, and adding my own code and design changes as CampusBites develops throughout the following weeks. My personal contributions and changes will also be documented based on the requirements of the project.
